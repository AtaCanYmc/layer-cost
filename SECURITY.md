# Security Policy

## Supported Versions

LayerCost actively maintains and supports the following versions with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in LayerCost, please report it responsibly:

1. **Do NOT create a public issue** on GitHub.
2. Email your vulnerability report to the repository maintainers or open a private GitHub Security Advisory.
3. Include detailed reproduction steps, potential impact, and suggested remediations if available.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you on a swift resolution.
